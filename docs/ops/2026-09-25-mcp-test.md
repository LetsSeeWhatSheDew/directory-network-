# MCP server test — 2026-09-25

Local test of the public PuffPrice MCP server (`app/mcp/route.ts`, logic in `lib/mcp/`) on branch `night/mcp`, against the live Supabase data (anon key, read-only; no writes).

**Setup:** `npx next build` (passed) → `npx next start -p 3077` → curl every method and tool, then the official TypeScript SDK client (`@modelcontextprotocol/sdk@1.30.1`, installed in a scratch folder only, not added to the app).

## Result

- Legacy era (initialize handshake, 2025-11-25 / 2025-06-18 / 2025-03-26): initialize, notifications/initialized (202), ping, tools/list, all five tools: pass.
- Modern era (2026-07-28, stateless per-request `_meta` + `MCP-Protocol-Version` / `Mcp-Method` / `Mcp-Name` headers): server/discover, tools/list, tools/call (plain and base64 `Mcp-Name`), ping: pass. Header mismatch → 400/-32020, missing `_meta` → 400/-32602, unknown version → 400/-32022 with `supported`, unknown method → 404/-32601: pass.
- HTTP: GET and DELETE → 405 (`Allow: POST, OPTIONS`, JSON or an HTML pointer for browsers), OPTIONS → 204 with open CORS, `Origin: null` → 403, malformed JSON → 400, batch → 400, `text/plain` → 415, `Mcp-Session-Id` ignored and never minted, 65 requests from one IP → 60 × 200 then 5 × 429 with `Retry-After: 60`.
- SDK client (`StreamableHTTPClientTransport`): connects, negotiates 2025-11-25, no session id, lists 5 tools, calls all five plus an out-of-scope city (isError), ping: pass.
- `/mcp/server-card` and `/.well-known/mcp-server-card` serve the card; `/developers` is 200; `/llms.txt`, the sitemap and the footer link `/developers`.

Numbers below are whatever was live at 6:4x AM CT on Sep 25, 2026. The jump in the Deal Index to 394 deals today (from 53 yesterday) is in `daily_market_stats` itself, not something the MCP server computes; it matches `/llms-full.txt`.

<details><summary>client.mjs</summary>

```js
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";
const url = new URL(process.argv[2] || "http://localhost:3077/mcp");
const client = new Client({ name: "sdk-test", version: "1.0.0" });
const transport = new StreamableHTTPClientTransport(url);
await client.connect(transport);
console.log("connected; negotiated protocol:", transport.protocolVersion, "| sessionId:", transport.sessionId ?? "(none)");
console.log("server:", JSON.stringify(client.getServerVersion()));
const { tools } = await client.listTools();
console.log("tools:", tools.map((t) => t.name).join(", "));
const calls = [
  ["find_deals", { city: "Springfield", category: "edible", max_results: 3 }],
  ["list_dispensaries", { city: "Urbana" }],
  ["out_the_door_price", { shelf_price: 25, category: "edible", city: "Springfield" }],
  ["illinois_cannabis_rules", { topic: "possession" }],
  ["deal_index", { city: "Normal" }],
  ["find_deals", { city: "Chicago" }],
];
for (const [name, args] of calls) {
  const r = await client.callTool({ name, arguments: args });
  const s = r.structuredContent || {};
  const brief = r.isError ? r.content[0].text : (s.summary || s.answer || (s.deals ? s.deals.map((d) => `${d.store}: ${d.title}`).join(" | ") : s.stores ? s.stores.map((x) => x.name).join(", ") : JSON.stringify(s.cities)));
  console.log(`\n${name} ${JSON.stringify(args)}\n  isError=${!!r.isError}\n  ${brief}\n  source_url=${s.source_url ?? "-"}\n  cite_as=${s.cite_as ?? "-"}`);
}
await client.ping(); console.log("\nping ok");
await client.close();
```
