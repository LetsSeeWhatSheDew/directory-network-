# Fraunces, Gold Leaf cut

Fraunces by Undercase Type, SIL Open Font License 1.1 (https://openfontlicense.org).
Source: the Google Fonts variable file (axes opsz, wght, SOFT).

These are static instances made with fontTools `varLib.instancer`, subset to
Basic Latin plus common punctuation:

- `Fraunces-SoftDisplay-Bold.woff2`: wght 700, SOFT 100, opsz 144
- `Fraunces-SoftDisplay-MediumItalic.woff2`: italic, wght 500, SOFT 100, opsz 144

To re-cut (for example, to add characters), instantiate the variable file at
the same axis values and subset again; keep the file names.
